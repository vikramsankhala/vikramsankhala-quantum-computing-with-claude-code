# qcwork: Quantum Computing with Claude Code, Codex CLI and Gemini CLI

Companion repository to the book *Quantum Computing with Claude Code* (Solinexta AI Press).
A small, fully tested NumPy implementation that builds quantum computing from first principles:
Hilbert space, the Schrödinger equation, operators, qubits, gates, circuits, algorithms, noise,
error correction, contextuality, variational methods, quantum ML, distributed circuits, QKD and sensing.

```bash
pip install -e ".[dev]"      # core + tests
pip install -e ".[all]"      # + Qiskit, PennyLane, stim, pymatching, MCP
python -m pytest -q
```

## Three agentic CLIs, one repository
`AGENTS.md` is the single source of truth. `CLAUDE.md` and `GEMINI.md` are generated by
`python scripts/sync_agent_files.py`, and a test fails if they drift.

| | Claude Code | Codex CLI | Gemini CLI |
|---|---|---|---|
| Project instructions | `CLAUDE.md` | `AGENTS.md` | `GEMINI.md` |
| MCP config | `.mcp.json` | `.codex/config.toml` | `.gemini/settings.json` |
| Install | see vendor docs | `npm i -g @openai/codex` | `npm i -g @google/gemini-cli` |

Each lab in `labs/lab-NN/PROMPT.md` runs unchanged in all three.

## Conventions
Qubit 0 is the most significant bit. Qiskit is little-endian, so cross-framework tests reverse bit order.
